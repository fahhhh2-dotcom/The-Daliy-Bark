How to fix it (for the site owner)
  1. Open console.firebase.google.com and pick the SkyCast project.
  2. Go to Firestore Database → Rules.
  3. Inside match /databases/{database}/documents { add these 3 lines, then press Publish:
match /arcade/{uid} {
  allow read, write: if request.auth != null && request.auth.uid == uid;
}
